Table of Contents

Classes

Dictionary
A PDF dictionary: keys are names, held without their slash, in the order they were read or set.
Document
An existing PDF, read far enough to revise it with an incremental update.
EncryptedPdfException
A PDF that is encrypted. New content added to it would have to be encrypted with the document's key, which is not supported, so the document is refused rather than damaged.
Filters
Decodes stream data through the filters its dictionary names.
IncrementalUpdate
Revises a document by appending new and changed objects to it, leaving its original bytes untouched.
Name
A PDF name, such as `/Type`, held without its slash and with `#xx` escapes decoded.
Page
A page of a document, with the attributes it inherits from the page tree already applied.
Parser
Reads PDF objects from bytes, following the object syntax of ISO 32000-1, section 7.3.
PdfException
A PDF that could not be read, or cannot be changed safely.
PdfString
A PDF string: its decoded bytes, and whether it was written in hex so it can be written back the same way.
Reference
A reference to an indirect object, written `12 0 R`.
Serializer
Writes PDF values in PDF syntax.
Stream
A PDF stream: its dictionary and its data, still encoded with whatever `/Filter` the dictionary names.
